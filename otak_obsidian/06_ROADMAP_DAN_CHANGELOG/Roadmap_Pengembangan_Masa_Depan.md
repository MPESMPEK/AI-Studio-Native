# 🗺️ Roadmap Fitur Masa Depan AI Studio Native

1. **SDXL & Flux.1 Turbo (Quantized GGUF)**: Mendukung arsitektur model difusi generasi berikutnya dengan konsumsi RAM rendah.
2. **In-Canvas Node Grouping**: Mengelompokkan node-node terkait ke dalam bingkai visual berwarna (*Node Frames*).
3. **Face Inpainting Native C++**: Deteksi dan regenerasi wajah otomatis (*Face Restore / ADetailer native*) pada resolusi rendah agar wajah selalu 100% sempurna tanpa perlu upscaling berat.
4. **Ekspor Workflow ke JSON**: Menyimpan dan membagikan skema visual alur kerja Studio Node dalam format file `.workflow.json`.
