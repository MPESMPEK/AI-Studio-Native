# 📸 Folder Model Gambar (Diffusion Checkpoints)

> **Lokasi:** `models/Gambar_Diffusion/`  
> **Format File yang Didukung:** `.safetensors`, `.gguf`

## Fungsi:
Folder ini adalah tempat checkpoint utama mesin difusi untuk menghasilkan foto ultra-realistis, seni digital, potret model, pemandangan, dan kreasi visual.

## Contoh Model yang Direkomendasikan:
1. **`CyberRealistic_V5_FP16.safetensors`** (~2.1 GB):
   - Model fotorealistis manusia terbaik dengan detail pori-pori kulit mikro, mata simetris jernih, dan pencahayaan alami (gunakan 20 - 25 steps).
2. **`Realistic_Vision_V5.1_fp16-no-ema.safetensors`** (~2.1 GB):
   - Standar industri untuk foto manusia, pakaian kasual, dan pemandangan luar ruangan.
3. **`DreamShaper8_LCM_q4_0.gguf`** (~1.6 GB):
   - Model difusi kuantisasi ultra-cepat khusus render kilat 4 langkah (Turbo LCM ~3-5 detik).
