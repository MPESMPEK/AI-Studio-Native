# 🚀 Riwayat Pembaruan Versi AI Studio Native

### v2.8.0 (26 Oktober 2026) - Security Hardened Release
- Menambal 5 celah keamanan (Command Injection `_popen`, `system()`, CLI backslash quote escape, path traversal session ID, dan buffer expansion).
- Sinkronisasi presisi parameter sampler & checkpoint saat eksekusi alur pipa visual.

### v2.7.0 (26 Oktober 2026) - Model Recommendations & Non-Destructive Prompts
- Tombol `[*] Rekomendasi` otomatis untuk tiap model (ChilloutMix, GhostMix, CyberRealistic, DreamShaper8).
- Panel Rekomendasi Kata Kunci di Node Prompt berbasis 4 tab (Model Aktif, 2 Orang, DSLR, Cahaya) dengan tombol non-destruktif `[+ Sisip]` dan `[Salin]`.

### v2.6.0 (26 Oktober 2026) - Model Expansion
- Penambahan checkpoint **ChilloutMix Ni** (2.03 GB) dan **GhostMix V2.0 Anime Realism** (2.29 GB).

### v2.5.0 - v2.0.0
- Dukungan resolusi kilat 250p & 380p.
- Penyesuaian layout Studio Node (spacing 60px/40px) dan penguncian skala font 1.0f.
