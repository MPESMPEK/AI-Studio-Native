# 💡 Node Prompt: Panel Rekomendasi Non-Destruktif

Sesuai permintaan pengguna, Node Prompt **100% NON-DESTRUKTIF**. Sistem **TIDAK PERNAH** menghapus atau menimpa tulisan prompt asli pengguna (`node.prompt[0] = 0` telah dihapus total).

## 🗂️ Panel 4 Tab Rekomendasi Kata Kunci:
1. **`[Model Aktif]`**: Saran kata kunci yang disesuaikan secara dinamis dengan model yang sedang terpasang di kanvas.
2. **`[2 Orang / Couple]`**: Contoh deskripsi terpisah (kiri/kanan) untuk mencegah wajah melebur menjadi satu.
3. **`[DSLR & Detail]`**: Lensa Canon 85mm f/1.4, pori-pori kulit alami, dan mata tajam.
4. **`[Pencahayaan]`**: Sunset golden hour dan softbox studio.

## 🛠️ Dua Tombol Kontrol Ramah:
- **`[+ Sisip di Akhir]`**: Menyambungkan kata kunci di ujung prompt dengan tanda koma pemisah otomatis.
- **`[Salin]`**: Menyalin teks rekomendasi ke Clipboard Windows agar pengguna bebas menempelkannya di mana saja.
