# 🧠 Folder Model LLM (Teks, Percakapan & Koding)

> **Lokasi:** `models/Teks_LLM/`  
> **Format File yang Didukung:** `.gguf` (Kuantisasi Q4_K_M, Q3_K_M, Q5_K_M, Q8_0)

## Fungsi:
Folder ini adalah tempat untuk meletakkan model bahasa besar (Large Language Model) untuk percakapan teks, penalaran logika, pemecahan masalah koding, dan pengembang prompt otomatis.

## Contoh Model yang Direkomendasikan:
1. **`DeepSeek-R1-Distill-Qwen-1.5B-Q4_K_M.gguf`** (~1.1 GB):
   - Model penalaran logika mendalam (*deep reasoning*), sangat cerdas dan hemat RAM.
2. **`qwen2.5-coder-1.5b-instruct-q4_k_m.gguf`** (~1.1 GB):
   - Asisten pemrograman kilat untuk C++, Python, HTML/JS, dan skrip batch.
3. **`qwen2.5-coder-7b-instruct-q3_k_m.gguf`** (~3.8 GB):
   - Model koding tingkat lanjut dan arsitektur sistem berskala besar.
4. **`Qwen3.8-2B-Uncensored-Q4_K_M.gguf`** (~1.3 GB):
   - Model percakapan santai bebas filter moral.
